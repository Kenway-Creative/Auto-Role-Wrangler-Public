# Role Wrangler — Public Showcase

**[Explore the interactive demo](https://kenway-creative.github.io/Auto-Role-Wrangler-Public/)**

A privacy-safe, static portfolio demonstration of Role Wrangler: AI-assisted UK SaaS sales role discovery, compensation research, suitability scoring and guarded application workflow design.

### What the demo demonstrates
- Interactive, responsive job discovery dashboard.
- Suitability scoring, compensation and application status examples.
- Product architecture, safeguards and application lifecycle.

**All displayed vacancies, scores, metrics and activity are fictional.** The demo does not submit applications or connect to private services.

### Implementation
Static HTML, CSS and JavaScript; GitHub Pages via Actions. The underlying private prototype separately uses Python, Supabase and Playwright. No private repository files, original CV, applicant responses, production credentials or private records are included here.

### Roadmap
Two parallel tracks: (A) prove reliable end-to-end application automation privately, then (B) develop a secure, multi-user SaaS product based on the validated engine.

### Deployment
In **Settings → Pages**, set **Source** to **GitHub Actions**. The included Pages workflow deploys only this public showcase. Never publish your private application engine repository.
